# Upstream data and licensing

This project downloads and transforms public rule data from these upstream projects:

- appshubcc/bett-rules: <https://github.com/appshubcc/bett-rules>.
- V2Fly domain-list-community (upstream of bett-rules geosite data): <https://github.com/v2fly/domain-list-community>, MIT.
- ttyyss2233/Tool (APNs rule list): <https://github.com/ttyyss2233/Tool>.

Generated rule files are derived from those upstream datasets. Preserve this notice,
the upstream attribution, and the applicable upstream license terms when publishing
or redistributing generated artifacts. The converter does not download or publish
proxy subscriptions, credentials, or private configuration files.
